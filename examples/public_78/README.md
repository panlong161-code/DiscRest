# Synthetic isolated clicks

`input.wav` is generated by `python -m discrest.synthetic`: 8 seconds, 44100 Hz, mono, three tones plus light hiss, and 12 clicks from 0.45 seconds at an interval of 0.55 seconds.

`run.yaml` enables declick and dehiss. The threshold is 16 times a robust standard deviation, and the replacement is LSAR. This run repairs 12 regions. Every action is `repaired`. There is no `dense-transient` flag.

```text
python -m discrest run --config examples/public_78/run.yaml
python -m discrest verify examples/public_78
```

Times in `clicks.csv` are the starts of replaced regions. The residual is `out/residual.wav`.
